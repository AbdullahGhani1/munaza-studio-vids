# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

Motion-graphics videos for Munaza Physio Studio (munazaphysio.studio, a women-only physiotherapy practice in Lahore led by Dr. Munaza Ghani). Each video is a plain HTML composition rendered to MP4 with the pinned [HyperFrames](https://github.com/heygen-com/hyperframes) CLI (`hyperframes` 0.8.79). There is no app, bundler, linter, or test suite. The project root is this directory (`munaza-physio-video/`), and **all commands run from here** because asset paths in the compositions are relative to it.

## Commands

```bash
npm install     # installs the pinned hyperframes CLI
npx hyperframes doctor                    # checks FFmpeg + headless Chrome are available

npm run preview            # 30s promo (index.html)
npm run render             # -> renders/munaza-physio-30s.mp4
npm run render:ur          # builds ur/index.html (scripts/make-urdu.js) then renders the Urdu-caption cut
npm run render:back        # series/01-back-pain  (1080x1920, 65s)
npm run render:complete    # series/complete      (1920x1080, 177s song video)
npm run render:neck        # series/03-neck-pain  (1080x1920, 177s)
npm run render:neck-short  # series/03-neck-pain/short.html (20s)
```

Series renders use `hyperframes render . -c <composition.html> --quality delivery`. There is no single-test equivalent; to check one moment, open a composition in a browser and scrub with `window.__timelines['<id>'].seek(<seconds>)` (id is `munaza-physio` for the root promo). Outputs (`renders/`, `ur/`, `*.mp4`) are gitignored.

CI (`.gitlab-ci.yml`, the project's original host is GitLab) installs ffmpeg + chromium and runs `render:en` / `render:ur` on any change under `munaza-physio-video/`. It only covers the root promo, not the `series/` videos.

## Architecture

- **Compositions are self-contained HTML files** (`index.html`, `series/*/index.html`) with inline CSS/JS. Motion is driven by a single *paused* GSAP timeline registered on `window.__timelines[<id>]`, so HyperFrames can render frames deterministically and in any order. Keep it that way: no timers, `Date.now()`, `Math.random()` (use seeded/precomputed values), or CSS animations outside the timeline. GSAP and fonts are vendored (`vendor/gsap.min.js`, `assets/fonts/`); don't add CDN dependencies.
- **Video timing follows the audio.** Scene and caption times are hand-aligned to the generated soundtrack (e.g. the `PH` array in `series/01-back-pain/index.html`, the `CAP` array in `series/complete/index.html`, `capTimes`/`talk` in the root `index.html`). If you swap an mp3, retime those arrays. Lyrics/scripts (`lyrics.md`, `script.md`, `*_lyrics.md`) are the source text, but generated tracks skip some lines and captions show only what is actually sung.
- **Urdu variant:** `scripts/make-urdu.js` copies `index.html` to `ur/index.html` with `<html lang="ur" data-lang="ur">`; Urdu text lives in `data-ur` attributes on `.cap` elements. The script string-matches `<html lang="en">`, so keep that tag exact.
- **`series/03-neck-pain/` is the most structured video**, a 2.5D paper-cut film split into modules:
  - `lib/paper.js`: engine; one GSAP-driven value `t`, every frame repainted as a pure function of `t`.
  - `lib/cast.js`: shared character rig (Ayesha, Dr. Munaza, mother); `lib/scenes.js` scenes; `lib/film.js` shot lists for both the 177s film (`index.html`) and the 20s short (`short.html`); `short30.html`/`lib/short30.js` is a 30s variant.
  - `data/`: narration text/timing (generated by `tools/tts.py`) and seeded logo particle targets (`logo-particles.js`, from `tools/logo_particles.py`). Captions derive from `narration-timing`, so edit `data/narration.json` and rerun `tools/tts.py`.
  - `audio/mix-*.m4a` are committed and are what the compositions play; `tools/mix.py` / `mix30.py` rebuild them (Python: kokoro-onnx, soundfile, numpy, plus ffmpeg loudnorm; steps in that folder's README). `audio/*.wav` is gitignored.
  - See that folder's README for details.
- **Content constraints** (from the brand brief in `munaza_physio_150s_hyperframes_master_prompt.md` and the neck-pain README):
  - No unsupported medical claims: no guaranteed recovery, cure, 100% results, or fixed recovery times.
  - Characters are modest by construction: hijab covers hair/neck/chest, garments are loose and opaque, and Dr. Munaza's mask always covers nose and mouth (no mouth is drawn).
  - The site's real pages (`assets/site/*.jpg` screenshots) and Poppins/Caveat/Archivo fonts are part of the brand look.
- `assets/posts/` holds many condition-poster PNGs (several duplicate/misspelled variants), and `assets/posts/LYRICS.md` the related lyrics. Treat the folder as source material rather than tidy, and check which file a composition actually references before renaming or deleting.
